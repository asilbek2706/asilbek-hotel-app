# Grand Hotel Uzbekistan

Minimalist static website for a modern hotel experience.

## What it is
- Multi-page hotel website built with pure **HTML**, **CSS**, and **JavaScript**
- Clean, responsive layout with consistent navigation across pages
- Lightweight and dependency-free

## Pages
- `index.html` — Home
- `rooms.html` — Room listing with filtering
- `booking.html` — Booking form with live price calculation
- `about.html` — Hotel story and values
- `contact.html` — Contact form

## Highlights
- Responsive header and mobile menu
- Smooth reveal/counter interactions
- Reusable UI styles and sections
- Accessible markup and form labels

## Run
Open `index.html` in your browser.
No install step. No build step.
